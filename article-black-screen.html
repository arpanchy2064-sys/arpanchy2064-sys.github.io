What to check when a laptop turns on but the screen is black

Updated September 2026 • 6 min read

A laptop can appear to power on while the display remains black. The cause can range from a temporary software issue to a display, memory or hardware problem. Start with the least invasive checks.

1. Check brightness and display output

Increase the brightness and make sure the laptop has not switched to another display. If you have an external monitor, disconnect it and try the laptop screen again.

2. Perform a normal restart

If the computer is responsive, use Windows to restart. If it is completely unresponsive, hold the power button only as a last resort and then start it again.

3. Disconnect accessories

Remove USB drives, hubs, external displays and other peripherals, then try starting the laptop again. A problematic peripheral can sometimes interfere with startup.

4. Check for signs of startup

Listen for the fan, watch the keyboard indicators and check whether the system responds to keyboard shortcuts. These observations help distinguish a display problem from a broader startup problem.

5. When to seek service

If the issue repeatedly returns, the laptop becomes unusually hot, shows physical damage, or will not display anything even after basic troubleshooting, contact the manufacturer's support or an authorized service center. Avoid opening a new laptop yourself if doing so could affect your warranty.
